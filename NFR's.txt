Non-Functional Requirements (NFRs)

Security:
- All APIs require OAuth token and RBAC enforcement
- Input validation on all endpoints
- Audit logging of all actions
- Data encryption at rest and in transit
- Parental consent for account management actions

Compliance:
- GDPR (data minimization, right to erasure, consent)
- PCI-DSS (secure payments, card data protection)
- ISO 27001 (information security controls)

Performance:
- API response time <500ms for 95% of requests
- Bulk transaction queries paginated, <1000 records per page

Scalability:
- Horizontal scaling of stateless APIs
- Container orchestration for microservices

Availability:
- 99.99% uptime SLA
- HA deployment across cloud regions

Reliability:
- Automatic failover for core services
- Retry logic for transient errors

Maintainability:
- Modular microservices
- OpenAPI/Swagger documentation
- Code review and CI/CD pipeline

Auditability:
- All user actions logged with timestamp, actor, action type
- Audit logs stored in immutable storage

Disaster Recovery:
- RTO <4 hours
- RPO <1 hour
- Geo-redundant backups

Backup:
- Daily encrypted backups
- Automated restore procedures

Monitoring:
- Real-time metrics collection
- Alerting for API errors, latency, security events

Logging:
- Centralized log aggregation
- Structured logs for all APIs

RBAC:
- Role-based access enforced via policy engine
- Parent-only access to youth account APIs

Input Validation:
- Strict schema validation on all request bodies
- Reject invalid or malformed input

Output Filtering:
- Only authorized data returned in API responses
- Sensitive data masked or omitted

Technical Debt:
- Legacy integration flagged for future refactor
- Manual RBAC policy until automated engine available

Mappings:
- Each NFR is mapped to ADRs SCIB-25 through SCIB-30
- Traceability matrix maintained in HLDDocument.txt
